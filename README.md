# 认知记忆层

> 借鉴人类记忆**若干特性**（不是全部）的 AI 长期记忆系统。
> 独立项目，**不依赖、不影响任何现有系统**。

---

## 状态

**设计完成，未实施。** 目前只有文档，没有代码。

---

## 这是什么

给长期陪伴型 AI 用的记忆层，解决三个问题：

1. **记不准** —— 现在逐句判断「值不值得记」，单句信息量不足，必然误判
2. **不知道自己在猜** —— 所有记忆条目平等，模型分不清「他说过」和「我推的」
3. **越攒越多** —— 46 条里 39 条是碎片，真正有用的被淹没

## 三句话概括方案

1. **不逐句判断值不值得记**，改成每 20 轮回看一段、只提炼「对这个人有没有新认识」
2. **每条记忆强制带来源**：`[事实]`（他说的）/ `[猜测]`（我推的），注入时分开放
3. **情绪参与记忆权重**，用进废退，跨层晋升靠反复出现而非单次触发

---

## 目标指标

| 指标 | 目标 |
|---|---|
| 记忆条数 | 10~15 条，**不是越攒越多** |
| 假记忆率 | 说出用户没提过的事 → 0 |
| 信息密度 | 每条都能单独回答「他是个怎样的人」 |
| 可解释性 | 任意一条能追溯到原文和来源 |

## 快速开始（等实现之后）

```js
import { Cognition } from './src/index.mjs';

const cog = new Cognition({
  dataDir: './data',
  llm: async (prompt) => await yourModel.chat(prompt),
});

// 记对话
cog.ingest({ speaker: 'user', text: '我是四川胃好吧 他们家我天天吃 还点的特辣' });

// 每 20 轮触发一次提炼
await cog.reconstruct();

// 每轮召回
const block = await cog.recall({ subject: 'user:884273334', queryText: '今天吃啥' });
// → （关于他的事实（他说过的，可以当真）：
//    - 他是四川人，能吃辣
//
//    你的猜测（不是他说的，别当事实讲）：
//    - 他可能不太喜欢被叫"大肥鱼"）
```

## 不做的事

- 不做向量数据库（字符重合 + 同类上限够用）
- 不做多模态记忆
- 不模拟人脑的遗忘缺陷（故意记错、联想扩散）
- 不做人格演化（v1 阶段）

**核心理念**：像人 ≠ 像人的缺点。真实感来自「有分寸」，不是「会出错」。
